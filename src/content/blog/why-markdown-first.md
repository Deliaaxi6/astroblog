写博客最重要的是内容本身，而不是平台的绑定。

## Markdown 的优势

1. **纯文本** — 任何编辑器都能打开，永不锁死
2. **可版本管理** — 用 Git 记录每一篇文章的修改历史
3. **可迁移** — 换框架时内容几乎零成本转移
4. **专注写作** — 不纠结排版，专心表达

## 常见的 Markdown 语法

```md
**加粗**、*斜体*、`行内代码`

- 列表项一
- 列表项二

> 引用块
```

## 结尾

把内容放在 Markdown 里，把平台的选择留在最后。
